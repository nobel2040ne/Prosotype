# Source

## The official release

`captionwithintention.org` publishes the system as open source. The complete release is five artifacts — there is no code repository, and the site itself is a Squarespace page whose only scripts are Squarespace's own. Verified 2026-08-11:

| artifact | note |
|---|---|
| `Caption-With-Intention_Design-System_V1.0.pdf` | The design system itself, 56 pages — the final word on any disagreement. |
| `cwi-quickstart-guide.pdf` | Two pages on the After Effects template workflow. |
| `Academy_CI_Template.aep` | The After Effects project the reference motion was authored in. |
| `cena-ci-template-v02a.mp4` | The footage that template is cut against, and the only artifact carrying audio. |
| `Instal Font - RobotoFlex.ttf` | The variable font the captions are set in; `scripts/fetch_font.py` downloads it to `assets/RobotoFlex.ttf`. |

**None of the four documents are redistributed here** — download them from `captionwithintention.org`.

## `PR_Flim.mp4`

The Caption with Intention PR film — 68.6 s, with audio. The motion reference: the only source where the design system's motion and the speech it captions are both real.
