## Reference materials

- `reference/` — the three screen recordings of the official CWI site, with
  transcripts, used to measure motion timing and per-word emphasis.
- `stills/` — individual frames kept for details easier to see than to describe.
- `Caption with Intention – Quickstart Guide.pdf` — the After Effects template
  workflow.

See [docs/RESEARCH.md — sources](RESEARCH.md#sources) for how these fit together and which
one wins when they disagree.
